# AI-агенти: Skills, MCP і контекст

Презентація для frontend-інженерів UPSTARS. 40 слайдів, ~24 хвилини доповіді + 5 хвилин Q&A.

## Файли

| Файл | Що це |
|---|---|
| `index.html` | Сама презентація. Один самодостатній файл, працює офлайн — просто відкрий у браузері |
| `ai-agents-handout.pdf` | Роздатка: усі слайди разом із нотатками спікера |
| `PLAN.md` | План доповіді: структура блоків, таймінг, джерела |

## Керування

| Клавіша | Дія |
|---|---|
| `←` `→` `Space` | Попередній / наступний слайд |
| `Home` `End` | Перший / останній слайд |
| `S` | Картки спікера — тези, таймінг слайда, «якщо спитають» |
| `O` | Список усіх слайдів для швидкого переходу |
| `T` / `R` | Таймер доповіді: старт-пауза / скинути |
| `F` | Повноекранний режим |
| `?` | Довідка по хоткеях |
| `Ctrl+P` | Друк: слайди разом із нотатками як роздатка |

Працює й на тачі — свайп вліво-вправо.

## Про що доповідь

1. **Skills** — формат, progressive disclosure, як писати description, портативність за відкритим стандартом Agent Skills
2. **Агенти** — чат vs workflow vs агент, анатомія циклу, звʼязок зі скілами, вибір моделі під роль
3. **MCP** — три примітиви, прихована ціна тулів, свій MCP-сервер як агрегатор для парку агентів
4. **Jev** — нова технологія типізованих рішень: що це, де дала б виграш, за яких умов її варто брати
5. **Токени** — always-on vs on-trigger, вимірювання, сім важелів економії
6. **Контекст проєкту** — граф коду, LLM wiki, автоматичне оновлення документації

Кожен блок побудований однаково: концепція → приклад у вакуумі → як це зроблено в наших проєктах.
